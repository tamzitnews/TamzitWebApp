# Icons

אייקוני קו מסט Lucide (גרסה 0.460, רישיון ISC), 24×24, קו 1.75 בממשק (2 בקבצים), קצוות מעוגלים. הקבצים כאן צבועים בדיו `ink` (#002653) לתצוגה; באפליקציה משתמשים ב־`Tamzit.Icon`, שיורש את צבע הטקסט.

שימושים קבועים: `newspaper` המהדורה · `history` ארכיון · `bookmark` / `bookmark-check` שמירה · `settings` הגדרות · `headphones` האזנה · `share-2` שיתוף · `message-circle-question` משוב · `flag` דיווח על טעות · `sunrise` / `sun` / `moon` / `flame` בוקר, צהריים, ערב, מוצאי שבת ושבת · `sprout` ונסיים בטוב · `star` פרימיום ותומך · `heart-handshake` תרומה · `users` משפחתי · `map-pin` קהילה · `feather` / `heart` / `list` / `smile` ארבעת הסגנונות · `lock` תוכן פרימיום.

כלי הצוות (חדר העריכה): `send` שלח · `zap` מהדורת בזק · `refresh-cw` רענן ונסה שוב · `arrow-up` / `arrow-down` סדר הידיעות · `pencil` עריכה · `bot` הסוכן ו־JEV · `package` חבילת ההפצה · `wifi` / `wifi-off` קו מחובר ומנותק · `mic` הקול · `megaphone` פרסומת ומפרסם · `grip-vertical` גרירה · `upload` העלאת תמונה · `tag` נושאים · `circle-alert` "שימו לב" (לא תקלה).
