# LevelMeter

מד החשיבות של ידיעה: שלושה ריבועים קטנים, מספר המלאים הוא הרמה. הריבוע לקוח ממוטיב המותג.

- `critical` (קריטי): 3 ריבועים ב־`critical`, והמילה "קריטי" ב־`critical-ink`. מה שמשפיע על הקורא ישירות, היום.
- `important` (חשוב): 2 ריבועים ב־`brand`.
- `general` (כללי): ריבוע אחד. ידיעות קלות ורקע.

המשמעות עוברת בכמות הריבועים ובמילה, לא בצבע בלבד. בידיעה המילה מוצגת רק ברמה הקריטית (`showLabel`); בלעדיה יש טקסט לקוראי מסך.
