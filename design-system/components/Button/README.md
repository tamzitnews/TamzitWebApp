# Button

כפתור בצורת גלולה (`radius-pill`, כמו באתר), בגובה 44px לפחות.

- `primary`: הפעולה הראשית, פעם אחת במסך (המשך, שליחה, הצטרפות).
- `secondary`: פעולה משנית, או מצב "לא נבחר" של כפתור דו־מצבי (האזנה, מועיל).
- `quiet`: פעולת טקסט (כבר מנויים? כניסה).
- `whatsapp`: רק לשיתוף בוואטסאפ.
- `sun`: רק להצעת פרימיום.

`size="lg"` בתחתית מסך, `block` לרוחב מלא, `icon` / `iconEnd` בשם אייקון, `href` הופך אותו לקישור. טקסט: פועל קצר בגוף רבים או שם פעולה ("המשך", "לתרומה"), בלי סימני קריאה.
