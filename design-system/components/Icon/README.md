# Icon

אייקוני קו מסט Lucide (רישיון ISC), קו 1.75 על רשת 24. הם יורשים את צבע הטקסט (`currentColor`).

- `name`: אחד מ־`Tamzit.ICON_NAMES`. `size` (ברירת מחדל 20), `strokeWidth`, `fill` לאייקון מלא (נגן, כוכב).
- `label`: רק כשהאייקון עומד לבד ונושא משמעות. אחרת הוא מוסתר מקוראי מסך.
- `flip`: חיצים שצריכים להתהפך בממשק משמאל לימין (אנגלית, צרפתית).

אין להשתמש באימוג'י בממשק.
