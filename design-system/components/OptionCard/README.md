# OptionCard

כרטיס בחירה עם כותרת, תיאור ודוגמה. לבחירת סגנון הכתיבה, רמת הידיעות ושפה.

- `name` ו־`value` כמו ב־radio; כרטיסים עם אותו `name` הם קבוצה אחת.
- `icon` או `media` (למשל `LevelMeter`) בצד ההתחלה.
- `sample`: ציטוט קצר שמוצג רק בכרטיס הנבחר, כדי שהקורא ישמע את הסגנון לפני שהוא בוחר.
- `checked`/`onChange` או `defaultChecked`.

נבחר: מסגרת `brand` ורקע `surface-tint`.
