# AdSlot

מקום הפרסומת היחיד במהדורה, למשתמשים בחינם. מסומן "פרסומת" ותמיד עם קישור "להסרת פרסומות".

`sponsor`, `children` (עד שתי שורות), `onRemoveAds` (פותח את מסך הפרימיום). בלי אנימציה, וידאו או צלילים, ובלי מעקב של צד שלישי. מופיע אחרי הידיעה האחרונה ולפני "בקהילה שלך", אף פעם לא בין שתי ידיעות קריטיות ולא ליד "ונסיים בטוב". אצל מנויי פרימיום ומשפחתי הוא לא מוצג בכלל.
