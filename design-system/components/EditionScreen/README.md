# EditionScreen

המסך הראשי: המהדורה האחרונה. `view` = `top` | `end`, `sheet` לגיליון המשוב, `premium` (בלי פרסומת), `period`, `items`.

סדר המהדורה: ראש המהדורה, הידיעות לפי חשיבות (קריטי קודם), פרסומת אחת (בחינם), "בקהילה שלך", "ונסיים בטוב", ו"זהו, אתם מעודכנים". הנגן קבוע מעל הלשוניות. התוכן כאן הוא דוגמה.
