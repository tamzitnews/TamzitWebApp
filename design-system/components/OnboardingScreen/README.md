# OnboardingScreen

ההתאמה האישית, ארבעה שלבים: `step` = `language` | `topics` | `rhythm` | `style`.

1. שפה: עברית, English, Français (אנגלית וצרפתית מתהפכות לשמאל־לימין).
2. נושאים: בחירה מרובה, ומהדורה קהילתית לא חובה. ידיעות קריטיות מגיעות מכל נושא.
3. קצב ורמה: תדירות (1, 2 או 3 ביום), שעות, ורמת הידיעות.
4. סגנון: מרגיע, אנושי, אינפורמטיבי או קליל, עם דוגמה חיה.

לכל שלב ברירת מחדל סבירה, כך שאפשר ללחוץ "המשך" ארבע פעמים ולקבל מהדורה טובה. הכל ניתן לשינוי בהגדרות.
