# Logo

הלוגו של תמצית החדשות, מקבצי המקור של האתר. אין לצייר אותו מחדש, לצבוע או למתוח.

- `variant="horizontal"` (ברירת מחדל): העיתון המגולגל והמילים, לרקעים בהירים. בערכת הכהה הרכיב מציג אוטומטית רק את הסמל, כי אין עדיין קובץ הפוך (לבן) של המילים.
- `variant="mark"`: הסמל לבדו. בסרגל העליון, באייקון האפליקציה, בכל מקום צר.
- `variant="vertical"`: הלוגו המלא עם "להתנתק ולהישאר מחובר" ו"מבית לוקחים אחריות". למסך "אודות" ולחומרים לחנויות. רקע הקובץ לבן, לכן בערכה הכהה הוא מקבל משטח `logo-plate`.
- `variant="parent"`: הלוגו של לוקחים אחריות, רק במסך התרומה ובאודות.

`height` בפיקסלים (ברירת מחדל 40). מרווח נשימה סביב הלוגו: לפחות חצי מגובהו. הלוגו לא יושב על `sky` או על תמונה.
