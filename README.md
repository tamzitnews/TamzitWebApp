# תמצית החדשות: אפליקציה

אפליקציית המובייל (אנדרואיד ואייפון) של תמצית החדשות.

## מה יש כאן

- `design-system/`: מערכת העיצוב והתכנון של האפליקציה.
  - `README.md`: ספר המותג (קול, צבע, טיפוגרפיה, מוטיב, לוגו, אייקונים, נגישות).
  - `app/01-plan.md`: תכנון האפליקציה (פיצ'רים, מסלולים, התראות, מצב שבת, תשלומים, טכנולוגיה, שלבים, החלטות פתוחות).
  - `app/02-screens.md`: מסכים וזרימות.
  - `app/03-editorial.md`: סגנונות, רמות חשיבות ומבנה המהדורה.
  - `tokens.json`: טוקנים של צבע (בהיר וכהה), טיפוגרפיה, ריווח, פינות וצללים.
  - `components/`: רכיבי React לדוגמה (`window.Tamzit`), תצוגות מקדימות והנחיות לכל רכיב, כולל מסכי האפליקציה המלאים.
  - `assets/`: לוגו, מוטיב ואייקונים.

בקובץ `components/bundle.js`, כתובות התמונות (`/_blob/...`) מצביעות על הקבצים במערכת העיצוב שפורסמה. מחוץ לה צריך להפנות אותן לקבצים שב־`assets/Logos`.
